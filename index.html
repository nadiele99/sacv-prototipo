Base do SILS · importação e status RF001 · RN027
A importação da base do SILS é uma ação exclusiva sua (Gerência) · os Analistas nunca importam, só acessam os registros já trazidos para dentro de um ciclo de análise (RF001/RN027). A base sobe uma vez e vale para todos os ciclos até que você importe uma nova; ela fica fixa durante todo o ciclo aberto (RN034/RN040).
Se você importar uma nova base enquanto houver ciclo(s) aberto(s), o sistema cancela automaticamente esse(s) ciclo(s) antes de aceitar o novo arquivo · a troca de base em ciclo aberto (reconciliação linha a linha) foi descartada como regra (RN049/RF036).
-

Depois de importar, use Regras padrão para definir filtros reutilizáveis com base nesses dados, e Ciclos de análise para abrir uma nova análise.

Controle de ciclos de análise RN034 · RF023
Nenhum analista consegue reivindicar ou analisar um município sem que você inicie um ciclo de análise. Cada ciclo pertence a um único tipo (Regular ou Indígena) · só pode haver um ciclo aberto por tipo ao mesmo tempo, mas Regular e Indígena podem estar abertos em paralelo, cada um com seu próprio painel, sempre usando a base vigente (veja Base do SILS). Um ciclo fecha automaticamente quando você valida o consolidado dele · a partir daí, é preciso iniciar um novo ciclo para aquele tipo.
